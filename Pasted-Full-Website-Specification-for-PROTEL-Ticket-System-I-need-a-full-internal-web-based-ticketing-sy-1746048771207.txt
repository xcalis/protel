Required Pages (HTML Interfaces):

	3.	add-ticket.html – Submit New Ticket
	4.	tickets.html – View Submitted Tickets
	5.	ticket-details.html – Complete ticket (must enter resolution note before completing)
	6.	my-achievements.html – Shows number of completed tickets (daily/weekly)
	7.	warnings.html – Displays admin announcements & warnings
	8.	admin-panel.html – Admin-only page to post company-wide messages
	9.	logout.html (optional) – Logout confirmation
	10.	404.html (optional) – Page not found

Functional Requirements:
	•	Tickets are saved per user in localStorage
	•	Ticket status: open / done
	•	Ticket cannot be completed unless the employee writes a “problem resolution”
	•	Warnings posted by admin are stored and visible to employees
	•	Completed tickets count toward the “Achievements” page
